\section*{Data availability}

Public NASA, NOAA, OMNI, and lunar archive products underpin the forecasts. Locked window tables, reconstructed series where noted, and figure sources are in the accompanying GitHub package under \texttt{papers/appendix\_numerical\_tables/} and \texttt{papers/elsevier/figures/}. Parts of the numerical record were reconstructed from locked \texttt{summary.json} and CSV exports; see Appendix~A and Appendix~D for where those files live and how to regenerate matching tables. Qualitative rubric files and reference lists are in Appendix~B.

\section*{Code availability}

Study runners, locked-model loaders, and reproduction steps are in the GitHub package under \texttt{studies/} with pointers in Appendix~D. Some scripts and tables were reconstructed to match the locked paper numbers; regenerated outputs should match or closely match the reported RMSE values when the locked blend and window definitions are used.
