\section{Results}
\label{sec:results}

Locked \texttt{saved\_model} (train-2) predictions were evaluated over two 14-day windows at three sites (equatorial reference $0^\circ$N~$0^\circ$E, Apollo~11, Nobile Rim). Window~A (5--18~July~2026) is lunar-night dominant; Window~B (22~July--4~August~2026) is lunar-day dominant and quiet in radiation. Blend weights are $[0.4, 0.05, 0, 0, 0, 0]$ for solar, radiation, temperature, moonquakes, micrometeorites, and dust. Skill charts use
\begin{equation}
\mathrm{skill}=96\times\max\!\left(0,\,1-\mathrm{RMSE}/\mathrm{scale}\right),
\end{equation}
with \texttt{scale} taken within each hazard across the three sites. Bars are deliberately \emph{not} height-normalized across hazards, so channel failures remain visible.

Figure~\ref{fig:wa-skill} and Figure~\ref{fig:wb-skill} show per-site absolute skill. \subsection{Interpretation of radiation across windows}
\label{sec:rad-interp}

Solar activity improves modestly in both windows. Radiation does not. In night-dominant Window~A, hybrid RMSE is 0.119 versus replica 0.102. In quiet dayside Window~B, absolute doses are much smaller, so the same $0.05$ neural blend produces a larger relative gap (0.0188 versus 0.00266): there is little storm signal for the neural path to learn from, ML predictions remain biased low, and the blend still pulls away from the cleaner physics/replica path. Hybrid radiation absolute error exceeded the replica on every site-day in both windows. Chronological holdout hybrid RMSE was approximately 4.97 versus approximately 13.66 for persistence.
